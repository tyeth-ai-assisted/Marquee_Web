## Integration changes

- Retain the Adafruit design system, current device tiles, live/sleep controls, backgrounds and layer controls.
- Apply per-image dithering to carousel pictures, expose the dither selector, and preserve it on save/load and conversion.
- Register linked-image and carousel frames as saved-order anchors, so late-decoding static images load underneath them when appropriate.
- Use the new small-caption font support for carousel attribution and placeholders.
- Keep Adafruit's custom Pages domain limited to the upstream repository.

## Deployment

The complete source branch is staged as `uat/2026-10-09-prs` in tyeth-ai-assisted. The requested destination is `tyeth/Marquee_Web:uat`.

For tyeth, first enable repository Actions if the fork has them disabled, then select **Settings → Pages → Source → GitHub Actions**. Allow the `uat` branch in the `github-pages` environment's deployment rules. Push the prepared commit to `uat`; **UAT Pages** tests, builds and deploys it. Later pushes redeploy automatically. The manual workflow button becomes available when the workflow also exists on the repository's default branch.

The output is plain static files rooted at `/Marquee_Web/`, with no inherited CNAME. `build.json` identifies the exact source commit. `node scripts/build-pages.mjs` reproduces the output in `_site/`.

Optionally set the public repository variable `ALBUM_WORKER_URL` to the deployed importer's HTTPS origin; the build writes that default into the frontend. Users can still override it under **Album → Importer connection**. The Worker must allow `APP_ORIGIN=https://tyeth.github.io` (no path), have its private `IMPORT_SECRET` set, and be deployed separately as documented in [worker/README.md](../../worker/README.md). GitHub Pages cannot run Worker endpoints. Without that connection, uploaded/local albums work, but remote URL imports do not.

The existing nightly workflow is included. Schedules run only from the default branch, so a UAT-only push does not activate nightly checks. Copilot repair additionally needs `COPILOT_AGENT_TOKEN` and enabled agent access; no token is included in the frontend or this branch.
