# Marquee Web

A browser-based canvas editor for **Adafruit IO Marquee** e-ink displays. It turns
what you draw into epaper-ready bitmaps entirely in the browser and publishes them
to Adafruit IO feeds. It is a static site: no server, no build step, and everything
it remembers lives in your browser's localStorage.

## Requirements

* Browser must be capable of Web Serial (Chrome, Edge, Firefox)

## Development
### Running Locally

There is nothing to install, this repo has no runtime or dev
dependencies. 

Bring up Marquee Web:
```sh
git clone https://github.com/adafruit/Marquee_Web.git
cd Marquee_Web
npm start
```

## Bitmap Rendering

Everything you draw on the canvas is rendered and palette-remapped by
`public/js/lib/bitmap.js`. Only pictures are dithered: each one is dithered on its
own, at the size it is drawn, with the panel's default or its own setting
(`public/js/lib/imagedither.js`). The whole panel is then snapped to the nearest
palette colour, so text, charts and shapes are never dithered. The server renderer
(`renderer/`) runs the same code.

`bitmap.js` is a pure-JS port of a subset of the ImageMagick CI pipeline and implements the following `magick` (ImageMagick) command only:
```
magick in.png -dither FloydSteinberg -define dither:diffusion-amount=N% \
  -remap eink-<type>.png gif:- | magick gif:- -compress none BMP3:-
```

## Shared Library

`public/js/lib/` is the part of the editor other hosts reuse: Adafruit IO's editor and
its server-side renderer copy it in at a pinned commit. It holds the element model
(`scene.js`: build, rebuild and serialize every element, and lay out a whole document),
the renderer (`render.js`, `bitmap.js`), palettes, formatting and the panel catalog.

Text draws in bundled faces, IBM Plex Mono, Sans and Serif (`lib/fonts.js`, files in
`public/fonts/`), so the editor and a server render show the same glyphs. Two bitmap
fonts from the Adafruit GFX Library sit beside them in the font menu, Tom Thumb 3×5 and
the classic 5×7 (`lib/pixelfont.js`, glyphs in `lib/pixelfont-data.js`, generated by
`scripts/gen-pixelfonts.mjs`): every pixel is ink or paper, drawn at whole multiples of
their native size like an Arduino sketch's `setTextSize`, which is what small text needs
on a panel. New charts default to the 5×7, and widgets caption themselves in a bitmap
font below 8 px.

Two rules, enforced by `test/lib-boundary.test.js`: a `lib/` module imports only other
`lib/` modules, and never touches the page (`document`, `window`, `localStorage`). Konva
is passed in by the caller rather than imported, so each host brings its own copy.
Editor state, the stage and DOM wiring stay in `canvas/`, `core/`, `device/` and
`screens/`.

## Server Renderer

`renderer/` renders a canvas.json to the panel's BMP with no browser, using `lib/` itself
(Konva on [skia-canvas](https://skia-canvas.org)). Adafruit IO runs it to keep displays
current while nobody has the editor open. It is the one part of the repo with dependencies,
kept in its own `package.json` so the editor stays install-free. See
[`renderer/README.md`](renderer/README.md).

## Credential Storage

Your Adafruit IO Key and Wi-Fi credentials are stored in your browser's `localStorage` and written to the hardware's USB MSC volume.
